# Laravel Doctrine ACL

Fork of the https://github.com/laravel-doctrine/acl that is not active anymore.

---

*ACL functionality for Laravel powered by Doctrine*

* Roles
* Permissions
* Organisations
* Seamless integration with Laravel's Authorization system
* PHP 8.2+ with Attributes support (annotations removed)

## Versions

Version | Supported Laravel Versions
:-------|:------
 ^1.5   | 11.x
 ^1.6   | 12.x

## Requirements

* PHP 8.2 or higher
* Laravel 11.x or 12.x
* Laravel Doctrine ORM ^1 or ^2.0

## Features

* User can belong to Organisation(s)
* User can have Roles
* User and Roles can have Permissions
* Uses PHP 8 Attributes for mapping relationships
* Seamless integration with Laravel's Authorization system
